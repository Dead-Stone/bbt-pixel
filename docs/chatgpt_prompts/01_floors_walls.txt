REFERENCE RESEARCH FIRST: Search the web for reference images of the floors, walls and doors of the 4th floor of 2311 Los Robles (apartments 4A and 4B and the hallway) from The Big Bang Theory. Write a short summary of colours and materials, then generate.

TASK: Make ONE pixel-art TILE sheet for an isometric Big Bang Theory game. Floor tiles are exactly one 64x32 px diamond each, with NO outline on their edges so they tile seamlessly: wood floor (3 variations), kitchen checker tile, hallway floor, carpet, bathroom tile, rug centre plus 4 rug edges. Wall pieces are 64 px wide x 160 px tall, in left-facing and right-facing versions: plain beige wall, cream wall, wall with window, wall with door frame, wall corner, baseboard. Doors closed and open: apartment door 4A, apartment door 4B, plain wooden door. Elevator with "out of order" tape, staircase going up 2x3, railing, wall lamp, mailboxes.

STYLE (match the attached character image exactly): true pixel art with hard pixel edges, no blur, no painterly strokes, no 3D render look. 1px dark brown outline around every object. Soft cel shading, 2-3 tones per colour, light from top-left. Warm, slightly muted palette matching the characters; objects must not be more detailed or more saturated than the characters.

VIEW: true isometric 2:1 (floor edges about 26.6 degrees), no perspective. Every object's front faces BOTTOM-LEFT. If an object is not symmetrical (couch, armchair, desk, chair, counter, island), also draw a second copy facing BOTTOM-RIGHT next to it, labelled with "R".

GRID AND SCALE: floor grid of diamond tiles 64 px wide x 32 px tall. Each object sits on a whole number of tiles; write its footprint under it as width x depth, e.g. "couch 3x1". Bottom corners line up with the footprint. Height scale 1 m = 53 px: door 112 px, seat cushion 24 px high, table top 40 px, counter 48 px, bookshelf 106 px. Same scale for all objects; never shrink big ones to fit.

SEATS: completely empty (no people, pets, clothes). Cushion top clearly visible and flat; backrest at the back edge; armrests don't cover the cushion.

BACKGROUND AND LAYOUT: flat pure magenta #FF00FF only, no gradient, texture or noise. No floor, no shadows of any kind, no glow. Never use magenta inside objects. Neat grid, at least 24 px of magenta between objects and from edges; nothing touches or overlaps; nothing cut off.

LABELS: small plain black text under each object with name and footprint, not touching the object, spelled as in the list.

DON'Ts: no characters or hands, no room walls/floor, no extra objects, don't merge objects, don't vary style.

OUTPUT: one lossless PNG about 2048 px wide (taller if needed). If it doesn't all fit, make a second image rather than shrinking. Before drawing, check every rule; after drawing, list anything that doesn't match the rules.

VIEW FIX: Use a true isometric 3/4 top view from above at the same angle for EVERY object, so the top surfaces are visible as 2:1 diamonds (the couch seat, table tops and counter tops must show as diamond-shaped tops). Do NOT draw objects from a straight front view.
